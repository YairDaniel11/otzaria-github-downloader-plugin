# הורדת ספרים

תוסף לאוצריא להורדה ועדכון של [מאגר הספרים המותאמים לאוצריא](https://github.com/YairDaniel11/Otzarya-Unofficial-Books).

## מסך ראשי: הורדת המסד (מגרסה 3.3.2)

המסך הראשי של התוסף הוא **הורדת המסד "מאגר ספרים לא רשמי"**: קובץ `.db` אחד שאוצריא פותחת כמו ספרייה, כולל הספרים,
הקישורים לספרייה הרשמית והדורות. אין צורך לחבר ולטעון אותם ידנית, והעדכונים מגיעים דרך אוצריא: היא מודיעה על עדכון זמין, ומורידה ומתקינה רק אחרי אישור המשתמש
בדיאלוג. אוצריא בודקת עדכונים בעליית התוכנה כש"סינכרון ומצב רשת" על "מקוון", "עדכוני תוכנה וספרים" ו"סינכרון הספרייה באופן אוטומטי"
מופעלים, לפי "תדירות בדיקת עדכונים"; אפשר גם ללחוץ ידנית "בדוק עדכונים" בכרטיס המסד.

- **הורד את המסד:** בוחרים תיקייה ייעודית למסדים ולוחצים "הורד את המסד". הקובץ נשמר בשם קבוע,
  `otzarya-unofficial-books.db`, בלי מספר גרסה. ההורדה היא `network.download` עם `resume:true`, ולכן לרוב נעצרת וממשיכה.
  אם המסד כבר מצורף באוצריא אין צורך להוריד שוב: הורדה חוזרת אל אותה תיקייה כותבת ישירות על הקובץ שבשימוש (עלולה להיכשל או להשאיר קובץ חלקי),
  ולכן התוסף מזהיר ומבקש אישור בהורדה חוזרת לאותה תיקייה, וההמלצה היא להוריד לתיקייה אחרת.
  אין אירועי התקדמות, ולכן מוצג פס "עובד" עם שעון.
- **מקור:** הגרסה והגודל נקראים מ-GitHub API (`api.github.com/repos/.../releases?per_page=100`, כתובת שכבר ב-allowlist):
  נבחר ה-release הגבוה ביותר בתבנית `db-v<N>` (לא draft/prerelease, השוואה מספרית), והקובץ הוא הנכס
  `otzarya-unofficial-books-<N>.db`. כתובת ההורדה נלקחת מהתשובה רק אם היא בדיוק
  `https://github.com/YairDaniel11/Otzarya-Unofficial-Books/releases/download/db-v<N>/otzarya-unofficial-books-<N>.db`, אחרת היא נבנית מהגרסה.
  הגבלת קצב (403/429) מוצגת כ"GitHub הגביל זמנית את הבקשות; נסה שוב בעוד כמה דקות". כשל בקריאה אינו שגיאה. אם בגרסה העליונה אין עדיין הנכס, מוצג "המסד עדיין לא זמין להורדה דרך התוסף"
  עם כפתור "פתח את דף הגרסה" (`app.openUrl`, הרשאת `app.open_url`). את `manifest.json` של המסד התוסף לא קורא: הכתובת שלו מפנה (302)
  לשרת שאינו ב-allowlist. הנכס נוצר ב-Action של מאגר הספרים.
- **אחרי ההורדה:** באוצריא, הגדרות ← ספרייה ← מסדי ספרים אישיים ← "ייבא קובץ מסד", ובוחרים את `otzarya-unofficial-books.db`
  (הדרך העיקרית). חלופה: "הוסף תיקיית מסדים" ובחירת התיקייה, ואוצריא מצרפת כל `.db` שבה. בכרטיס המסד אפשר לבחור
  "בנפרד" (הספרים תחת "ספרים אישיים") או "ממוזג" (הספרים משולבים בקטגוריות הקיימות).
- **עזרה והסבר:** דף מפורט (מה במסד, צירוף ראשון, איך עובדים העדכונים, מה לעשות בכשל). צילומי המסך נטענים מ-`src/img/`
  לפי השמות שב-[`src/img/README.md`](src/img/README.md); תמונה שחסרה מציגה מסגרת "תמונה תתווסף".
- **הורדת ספרים כקבצי TXT:** כפתור בולט במסך הראשי שמעביר לתצוגה הקודמת (עץ התיקיות, חיפוש, עדכון שינויים, קבצי קישורים,
  התעלמות משס וגשל), כפי שהייתה, עם כפתור חזרה. בלחיצה על "הורד הכל" שם קופץ חלון שממליץ על המסד, עם אפשרות
  "אל תציג שוב" (`hide_db_recommend` באחסון התוסף).
- **קבצים:** `src/dbview.js` (ממשק), `src/dbmodule.js` (לוגיקה טהורה), בדיקות ב-`tests/dbmodule.test.js`.
- **הרשאת רשת:** כתובות ההורדה נמצאות תחת `https://github.com/YairDaniel11/Otzarya-Unofficial-Books`, שכבר ב-`network.allowlist`.
  הרשימה הרשמית של אוצריא (`plugin_network_allowlist.txt`, ענף `dev`) צריכה להכיל קידומת שמכסה את `/releases/download/`.

## למה התוסף משמש (תצוגת TXT)

מאגר הספרים כולל קבצים רבים וגדולים, והורדה רגילה שלו דרך כפתור "Download ZIP" של GitHub עלולה לשבש אותם.
התוסף מוריד את הספרים ישירות לתוך תיקייה שתבחרו, ומחלץ אותם במבנה התיקיות של המאגר.

מה אפשר לעשות בו:

- **להוריד ספר, תיקייה או את המאגר כולו** מתוך עץ התיקיות, עם חיפוש מהיר.
- **לדעת מה השתנה** — סימון "מעודכן" / "יש עדכון" לכל פריט, תצוגת "חדשים ועדכונים", והורדה של השינויים בלבד במקום אוסף שלם.
- **לעדכן בלחיצה אחת** את כל מה שהורדתם כבר ("עדכן שינויים").
- **להתעלם משס וגשל** (תיקייה גדולה במיוחד בתוך "תלמוד בבלי") ולא להוריד אותה.
- **להוריד את קבצי הקישורים וסדר הדורות** בקובייה נפרדת. הקבצים האלה מקשרים בין ספרי המאגר למאגר הכללי של אוצריא, ומשייכים כל ספר לדור שלו. את הקבצים טוענים באוצריא דרך **הגדרות ← ספרייה ← ייבוא דורות וקשרים**.

הספרים עצמם, ההוראות להוספת ספרים, וההבהרות לגבי זכויות יוצרים ושימוש פרטי נמצאים במאגר הספרים:
**[Otzarya-Unofficial-Books](https://github.com/YairDaniel11/Otzarya-Unofficial-Books)**

## מחיקת קבצים ישנים אחרי עדכון (מגרסה 3.3.0)

התוסף מחלץ zip מעל התיקייה, ולכן קובץ שהוסר או ששונה שמו במאגר היה נשאר אצל המשתמש לצד הקובץ החדש (אותו ספר פעמיים באוצריא).
מגרסה 3.3.0 התוסף מוחק את הנתיבים הישנים:

- ה-workflow של [מאגר הספרים](https://github.com/YairDaniel11/Otzarya-Unofficial-Books) בונה בכל פרסום את `removed_files.json`
  מהיסטוריית git: רשימת נתיבים שהוסרו או הועברו (ואיפה שהועברו), בלי נתיבים שחזרו להתקיים.
- אחרי חילוץ **מוצלח** של אוסף, התוסף מוחק מתיקיית המשתמש את הנתיבים הישנים ששייכים לאוסף הזה (`fs.deleteFile`). העברה שייכת לאוסף
  של היעד, ולכן הקובץ הישן נמחק רק אחרי שהחדש כבר בדיסק. הורדה ראשונה של אוסף לא מוחקת כלום.
- מה כבר הוחל נשמר לכל תיקיית יעד ואוסף (`removed_applied` באחסון התוסף). כשל במחיקה לא מתקדם, והניסיון חוזר בעדכון הבא.
- רשומה עם נתיב לא בטוח (`..`, נתיב מוחלט, אות כונן, backslash או תווי בקרה) נזרקת בפענוח (מגרסה 3.3.1). אוצריא עצמה חוסמת מחיקה מחוץ לתיקייה שנבחרה.
- אוצריא ישנה מ-0.9.93 (בלי `fs.deleteFile`) פשוט לא מנקה, כמו בגרסאות קודמות.
- הקוד ב-`src/removals.js`, בדיקות: `node --test tests/`.

## התקנה

- **מחנות התוספים:** [otzaria.org/plugins](https://otzaria.org/plugins/6a0081ae54ae49eaed8d6a73) — העדכונים מגיעים אוטומטית.
- **ידנית:** הורידו את קובץ ה-`.otzplugin` מדף ה-[Releases](../../releases) ובאוצריא: **הגדרות ← ניהול תוספים ← התקנה מקובץ**.

הקוד עצמו נמצא תחת `src/`, וקובץ ה-`.otzplugin` נבנה ממנו.

## פרסום גרסה חדשה

הפרסום אוטומטי. כל מה שצריך הוא לעדכן את `version` בתוך `src/manifest.json`
ולדחוף ל-`main`:

```bash
git add -A
git commit -m "תיאור השינוי"
git push origin main
```

מכאן [הריצה](../../actions) בונה את התוסף, מוציאה תג `vX.Y.Z` ו-GitHub Release,
ומעדכנת את החנות ב-otzaria.org. אם הגרסה ב-manifest לא השתנתה — הריצה מדלגת
בשקט, כי החנות דוחה ממילא העלאה של גרסה שכבר קיימת.

מספור הגרסאות: הספרה האחרונה עולה עד 9 ואז מתגלגלת — `1.0.9` הופך ל-`1.1.0`.

## בנייה מקומית

```powershell
.\build.ps1
```

נוצר `otzaria-github-downloader.otzplugin` בשורש. באוצריא: **הגדרות → ניהול תוספים → התקנה מקובץ**.

## סודות שהריצה צריכה

| שם | תפקיד |
|----|-------|
| `OTZARIA_USER` | שם המשתמש / האימייל בחשבון otzaria.org |
| `OTZARIA_PASSWORD` | הסיסמה לאותו חשבון |
| `OTZARIA_PLUGIN_ID` | מזהה התוסף בחנות (ה-`id` מ-`/api/plugins`, לא ה-`id` שבמניפסט) |

בלי שלושתם שלב הפרסום לחנות מדולג, וה-Release עדיין נוצר — כך שתמיד אפשר
להתקין ידנית מהקובץ.
