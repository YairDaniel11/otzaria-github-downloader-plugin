# מתקין וקטורי חיפוש לפי משמעות (אוצריא)

כלי עצמאי (חלון + כפתור אחד) שמוריד ומתקין את הוקטורים של "מאגר ספרים לא רשמי" בסט של אוצריא.
הוא קיים כי תוסף אוצריא אינו יכול לעשות זאת (התוסף רץ בתוך אוצריא, ואין ב-SDK פריסת zstd וכתיבה בינארית).

## למשתמש
1. סגרו את אוצריא. 2. ודאו שהמסד של המאגר מותקן בגרסה האחרונה. 3. הריצו את הקובץ ולחצו "התקן את הוקטורים".
הכלי מאתר הכול לבד, מאמת חתימה ו-sha256, ומציג הסבר בעברית אם משהו לא מתאים.

## מה הוא בודק לפני כל שינוי (כשל = לא משנה כלום)
חתימה (ed25519 מול המפתח הציבורי של המסד), אוצריא סגורה, התאמת מודל, גרסת המסד המותקן = `db.version` במניפסט,
שאין כבר וקטורים לספרי המאגר (גם בתוך דור מכווץ), מקום פנוי, sha256 וגודל. `CURRENT` נכתב אחרון.

## מגבלות
- התקנה ראשונה בלבד. אם כבר הותקן מקטע קודם שלנו, הכלי מסרב (עדכון טרם נבדק מול כיווץ של אוצריא).
- Windows בלבד נבדק. אין המשך הורדה (השרת לא תומך): הורדה שנקטעה מתחילה מחדש.
- לא נבדקה התקנה מלאה מול סט אמיתי של אוצריא. נבדקו הבדיקות הסינתטיות והבדיקה הקריאה-בלבד (`--check`).

## למפתחים
- בדיקות: `python -m unittest -v` (בתיקייה הזו). בדיקה מול המניפסט האמיתי בלי התקנה: `python vectors_installer.py --check`.
- בנייה: `.\build_exe.ps1`.
- `vectors_core.py` נגזר מ-`cmd_install` (`vectors_ci.py`) ומ-`publish_generation` (`otzaria_personal_vectors.py`) במאגר הספרים, בלי numpy.
